데이터 편향: 데이터가 한쪽으로 치우치면 AI의 판단도 치우친다

      

      

        

          
⚖️ 우리 분리수거 AI의 편향

          

            
① 양의 편향 (클래스 불균형)캔 12장 vs 페트병 40장 → 애매하면 많이 본 '페트병'으로 판단

            
② 다양성 편향 (대표성 부족)똑바로 선 캔만 학습 → 찌그러진 캔은 처음 보는 모양

            
③ 환경 편향흰 책상 배경에서만 촬영 → 다른 배경·조명에서 실수

          

          
🌏 실제 사회에서도: 특정 피부색·성별에서 얼굴 인식 오류가 더 높게 나타나거나, 과거 데이터를 배운 채용 AI가 한쪽 성별에 불리하게 판단한 사례가 있어요.

        

        

          
🛠️ 편향의 해결·완화 방법

          
    
            
  • 1균형 맞추기 — 클래스별 데이터 수를 비슷하게, 부족한 쪽을 더 모으기
    • 
            
  • 2다양하게 모으기 — 모양·각도·배경·조명·사람을 바꿔 가며 촬영
    • 
            
  • 3데이터 증강 — 회전·뒤집기·밝기 조절로 데이터 늘리기
    • 
            
  • 4테스트로 점검 — 학습에 안 쓴 데이터로 조건별 정확도와 오분류 확인
    • 
            
  • 5사람이 검토 — 레이블이 맞는지, 빠진 경우가 없는지 여러 사람이 확인
    •
